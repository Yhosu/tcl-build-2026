# Carpeta de Documentos Descargables

Aquí se almacena el archivo oficial de las Bases y Condiciones descargables.

## Archivo actual:
- `bases-y-condiciones.pdf`

## Cómo actualizar o cambiar por Word / PDF:
1. Si tienes un nuevo PDF, simplemente guárdalo aquí con el nombre `bases-y-condiciones.pdf` reemplazando el existente.
2. Si prefieres usar un archivo Word (.docx):
   - Coloca tu archivo aquí: `public/docs/bases-y-condiciones.docx`
   - En `src/components/Footer.jsx` (y en `src/components/RequirementsSection.jsx` si aplica), cambia la ruta a `/docs/bases-y-condiciones.docx`.
